# API 集成测试清单

## 测试环境
- 微信开发者工具
- API 基础地址: `https://yimei.wenzhouwenlian.cn/api`
- 千问视觉 API: `https://yimei.wenzhouwenlian.cn/api/open/vision/qwen-face/analyze`

## 测试步骤

### 1. 基础功能测试

#### 1.1 图片上传与分析
- [ ] 点击"上传图片"按钮
- [ ] 选择一张清晰的正面照片
- [ ] 等待分析完成
- [ ] 验证返回的 `faceVisionAnalysis` 结构:
  - [ ] `status` 为 "completed"
  - [ ] `provider` 为 "qwen"
  - [ ] `model` 为 "qwen3-vl-plus"
  - [ ] `issues` 数组包含识别到的问题
  - [ ] 每个 issue 包含 `box` 坐标、`confidence`、`possibleOptions` 等字段

#### 1.2 文本追问
- [ ] 在输入框输入问题,如"这个需要重点关注什么?"
- [ ] 点击发送
- [ ] 验证 AI 回复正常
- [ ] 验证 `conversationId` 被正确保存

### 2. 历史记录功能测试

#### 2.1 历史记录恢复
- [ ] 完成一次完整的图片分析对话
- [ ] 发送 2-3 条追问消息
- [ ] 关闭微信开发者工具或重新编译
- [ ] 重新打开智能体页面
- [ ] 验证页面自动恢复历史记录(如果 `ENABLE_DIAGNOSIS_HISTORY_RESTORE` 为 true)
- [ ] 或点击"历史记录"按钮手动恢复
- [ ] 验证以下内容:
  - [ ] 用户消息正确显示
  - [ ] AI 回复正确显示
  - [ ] 图片消息正确显示
  - [ ] 诊断报告完整恢复(包括面部问题识别、局部图等)
  - [ ] 最近上传的图片路径被正确缓存

#### 2.2 历史记录限制
- [ ] 发送超过 20 条消息
- [ ] 恢复历史记录
- [ ] 验证只显示最近 20 条消息

#### 2.3 新对话功能
- [ ] 在有历史记录的情况下
- [ ] 点击"开启新对话"按钮
- [ ] 确认清空操作
- [ ] 验证:
  - [ ] 消息列表被清空
  - [ ] 回到欢迎页
  - [ ] 会话 ID 被清除
  - [ ] 缓存的图片被清除

### 3. 视觉分析结果展示测试

#### 3.1 面部问题识别卡片
- [ ] 上传包含明显特征的面部照片
- [ ] 验证"面部问题识别"区域显示正确
- [ ] 验证每个问题项包含:
  - [ ] 序号
  - [ ] 类别标签
  - [ ] 问题标题
  - [ ] 详细描述
  - [ ] 关注程度、优先级、置信度
  - [ ] 可讨论方向

#### 3.2 识别框坐标
- [ ] 验证 `box` 坐标 `[x1, y1, x2, y2]` 是原图像素坐标
- [ ] 验证 `imageSize` 包含正确的图片宽高
- [ ] 如果有标注图,验证标注位置正确

### 4. 错误处理测试

#### 4.1 网络错误
- [ ] 断网状态下上传图片
- [ ] 验证错误提示正确显示
- [ ] 恢复网络后重试成功

#### 4.2 会话不存在
- [ ] 手动设置一个不存在的 `conversationId`
- [ ] 尝试恢复历史记录
- [ ] 验证错误提示
- [ ] 验证会话 ID 被清除

#### 4.3 识别失败
- [ ] 上传不清晰或不包含人脸的图片
- [ ] 验证 `faceVisionAnalysis.status` 为 "failed"
- [ ] 验证错误信息正确显示

### 5. 性能测试

#### 5.1 超时处理
- [ ] 上传大尺寸图片(>5MB)
- [ ] 验证超时设置(600秒)生效
- [ ] 验证超时错误提示

#### 5.2 历史记录恢复时间
- [ ] 记录恢复 20 条历史记录的时间
- [ ] 验证在可接受范围内(< 5秒)

## 预期结果

所有测试项都应该通过,如果有失败项,请记录:
- 失败的测试项
- 错误信息
- 重现步骤
- 实际结果 vs 预期结果

## 注意事项

1. 测试前确保配置文件 `utils/miniapp-open-config.js` 中的 API 地址和 Key 正确
2. 测试用户需要有效的 `openid`
3. 建议使用真机测试部分功能,以验证实际运行效果
4. 测试完成后记得清理测试数据
